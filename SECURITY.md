# Security policy

This policy applies to all repositories of the [nomux-sh](https://github.com/nomux-sh) organization.

## Supported versions

nomux is in development. There is no public release.

| Version | Supported |
|---|---|
| Earlier than 1.0.0 | No |

Versions earlier than 1.0.0 are internal development versions. They do not get security updates. Security support starts with version 1.0.0.

## How to report a vulnerability

Do not report a vulnerability in a public issue, a discussion or a pull request.

Use GitHub private vulnerability reporting:

1. Open the affected repository on GitHub.
2. Select the **Security** tab.
3. Select **Report a vulnerability**.
4. Fill in the form and submit it.

Refer to the GitHub documentation about [privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

Include this information in the report:

- The affected repository, component and version or commit.
- The steps to reproduce the problem.
- The effect of the problem.
- A proof of concept, if you have one.

## What to expect

- The maintainers read each report and answer in the advisory.
- The maintainers keep the report private until a correction is available.
- The advisory gives credit to the reporter, unless the reporter does not want it.

nomux has no bug bounty program.
